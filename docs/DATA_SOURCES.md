## Greek Field Contract

MorphGNT source rows have seven whitespace-separated columns, zero-indexed:

| Index | Meaning |
| --- | --- |
| 0 | Book/chapter/verse reference |
| 1 | Part of speech |
| 2 | Eight-position parsing code |
| 3 | Text including punctuation |
| 4 | Word with punctuation stripped |
| 5 | Normalized word |
| 6 | Lexical lemma |

The parsing positions are person, tense, voice, mood, case, number, gender,
degree. POS is separate. Source imperative mood is `D`; perfect/pluperfect are
`X`/`Y`. Do not confuse these with Robinson-style codes.

The canonical importer preserves all seven fields without Unicode rewriting:
reference/source locator, `pos`, `morph`, punctuated `text`, unpunctuated `word`,
`normalizedWord`, and `lexicalLemma`. It adds corpus/reference/ordinal-based
stable IDs and language metadata. Canonical NT `lemma` and `strongs` legacy
fields are intentionally empty. No fabricated Strong's lookup or fuzzy join is
needed for reading/research. The active Inspector parser handles imperative `D`,
separate source POS and degree; `services/MorphDecoder.ts` is not that path.

Legacy converters lost lexical lemma/POS and emitted Strong's IDs as `lemma`.
That limitation explains why legacy XML cannot be research identity, not a future
blocker of the now-implemented canonical path. Do not run the old converters to
validate or repair canonical NT data.

Exact and accent-stripped dictionary matching can overwrite collisions and yield
ambiguous links. Strong's linkage must remain distinct from lemma identity. Missing
or ambiguous links should stay unresolved rather than receive fabricated IDs.
Normalize lookup copies only under a documented policy; preserve source spelling.

Research keys use NFC only: lexical lemma for lemma search, unpunctuated `word`
for form search, case/accent sensitive. Romans 8:9 preserves `σαρκὶ` (surface),
`σαρκί` (normalized word), `σάρξ` (lemma), `N-`, `----DSF-`. The normalized word
is neither a fallback lemma nor the form-search key. Editorial marks such as
Romans 8:1 `⸀Ἰησοῦ·` remain in display text.

## Canonical Build and Coverage

The verified generator output contains 27 books, 137,554 tokens and 7,927 source
verse references; gzip book shards total 3.64 MiB. This is measured generator
output, not a browser transfer/latency measurement or all-asset offline budget.
`npm run build:nt` generates; `npm run check:nt` invokes `--check`, reconstructing
expected exact bytes and checking output inventory read-only. Source inputs must
match all 27 pinned SHA-256 values; no normal build/CI upstream download occurs.
Corpus identity includes importer signature and source metadata. Manifest records
source revision/URL, hashes, notices and reference coverage; runtime checks shard
SHA-256 and schema/corpus identity before use. No NT XML fallback is allowed.

The pinned stream is not latest SBLGNT and does not include John 7:53-8:11,
added to official SBLGNT v1.2 in July 2023. Numeric gaps and known absent
references describe this source, not every traditional verse or all manuscripts.
Numbering is edition-specific (Romans ends at source reference 16:24); do not
infer missing text solely from another edition's numbering. Do not insert newer
text or guess annotation alignment. All 27 books does not mean all readings.

`data/nt-author-groups.json` defines Pauline seven-letter, additional six-letter,
and thirteen-letter comparison presets; Hebrews is excluded from all three.
Its [Wikipedia authorship citation](https://en.wikipedia.org/wiki/Authorship_of_the_Pauline_epistles)
is an introductory reference, not a primary or definitive scholarly source.
Presets expose selected membership and uncertainty, not settled author identity.
The UI's Other NT books excludes the thirteen-letter set and includes Hebrews.

## Hebrew and XML Contracts

Preserve Hebrew vowels, cantillation, slash segmentation, punctuation, token order,
and `H`/`A` morphology language markers. Aramaic is not automatically Greek, nor
should script direction depend on a successful dictionary lookup.

Preserve OSIS IDs, namespaces, attribution headers, and supported container and
milestone/flat retrieval layouts. Verse numbering is edition-dependent; do not
assume all corpora align with a single English versification. Use structured XML
parsers for validation and transformations, not regex-based schema validation.

## Known Limitations and Change Review

- Hebrew decoding tables are partial; do not claim comprehensive coverage of
  every OSHM/Aramaic form from a handful of tests.
- Canonical NT tokens have no Strong's linkage. The Inspector looks up exact NFC
  Greek headwords from the separately bundled historical Greek lexicon using the
  canonical source lemma; it does not create Strong's links. Missing, ambiguous,
  and unavailable entries remain distinct. This is a direct headword match, not
  a modern lexicon, scholarly certification, or contextual meaning.
- Alternate generators and legacy master assets are not all interchangeable.
- The Hebrew digital lexicon's exact edition and rights remain incompletely
  documented; the Greek asset's declared public-domain status and e-text/XML
  attribution are recorded above, not independently adjudicated.

Canonical NT field preservation and active Greek decoding were repaired in the
authorized sprint. Hebrew display/decoding, independent verification of the
historical Greek dictionary's accuracy, and Hebrew lexicon provenance/rights
remain separate limitations. Passing structural tests is not linguistic certification.

For an explicit corpus change: select source/version/license and canonical
generator, define field mappings, use small authentic fixtures, compare Unicode,
reference order, token counts, lemma/POS/morphology, and report missing/ambiguous
links. Review generated differences separately from UI or infrastructure changes.
Do not manually patch entire corpora or regenerate them as a routine test; use
read-only `check:nt` for reproducibility. LXX ingestion and cross-corpus alignment
remain deferred. Read the selected source's declared terms before a later import:
[CCAT/CATSS terms](https://ccat.sas.upenn.edu/gopher/text/religion/biblical/lxxmorph/0-readme.txt)
restrict commercial use without consent and impose redistribution conditions;
do not invent a blanket hosting prohibition or treat public access as permission.
Daily Dose of Greek links/source lookup also remain deferred.
